# Items

One page per thing the player can grow, build, make or hold. Other pages link here, for example "the Mill takes `MILL_IN` [[items/crops/sugar-cane]]".

An item page says what the thing is, how the player gets it, how it sells, and which mechanics change it. It does not list the recipes or buildings that use it. A machine's page holds that machine's recipes; the shared machine rules are in [[features/machines]]. A thing with variants (varieties, tool grades, jam flavours) has one page.

| folder | holds | template |
|---|---|---|
| `crops/` | annual crops and tree species | [[items/crops/_template]] |
| `buildings/` | everything placed on the map, including the starting buildings | [[items/buildings/_template]] |
| `produce/` | goods sold at the Market that are not raw fruit, plus the two machine products used only for infusion | [[items/produce/_template]] |
| `other/` | tools, bags, containers, vehicles, and items picked up or dropped on the farm | [[items/other/_template]] |
