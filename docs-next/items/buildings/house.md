# House

| | |
|---|---|
| SKU | starting building; not sold |
| size | 4 × 3 (`HOUSE_BASE`) |
| demolish | no |
| cell kind | `'house'` |

The gardener's house. Its door (`DOOR`) is where the inventory is opened, where every gardener starts, and where items that cannot go elsewhere are dropped.

## Use

**Inventory** walks the gardener to the door and opens the seat's inventory ([[features/inventory]]). Contract prizes that do not fit in the [[items/buildings/postbox]] are dropped at the door.
