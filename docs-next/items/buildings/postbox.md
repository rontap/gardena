# Postbox

| | |
|---|---|
| SKU | starting building; not sold |
| size | 1 × 1 (`POSTBOX_BASE`) |
| demolish | no |
| cell kind | `'postbox'` |

Receives contract prizes that are items: tree seeds and tools ([[features/contracts]]).

## Use

`POSTBOX_SLOTS` slots. Clicking a slot takes the item into an empty hand. The player cannot put items in. A prize that arrives with no empty slot is dropped at the house door.
