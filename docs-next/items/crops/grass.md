# Grass seed

Seeds that turn a tilled plot back into untilled grass ground. Sowing uses the prompt **Sow grass**. The plot becomes turf, which uses `GRASS_WATER_PER_SEC` water and after `GRASS_GROW` seconds becomes soft untilled ground with a grass cover; the plot's soil is removed. Turf has no happiness, no fertilizer use and no fruit ([[features/weeds]]).
