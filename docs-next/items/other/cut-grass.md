# Cut grass

| | |
|---|---|
| item kind | `'grass'` |
| unit | count |
| stack limit | `STACK_MAX` (+ `bulk-up`) |
| obtained from | **Pick up** on a grass tuft on untilled ground |
| sold at | not sold |

Picked from wild grass. Picking it leaves bare ground.

## Variants

None. Grass seed (`seeds` with `crop: 'grass'`) is a different item.

## Use

Carried and stored like other counted items. It does not lose freshness.
