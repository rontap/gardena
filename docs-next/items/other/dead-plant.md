# Dead plant

What is left of a plant that died. It carries the crop class (`cls`) and stacks only with the same class. Name: **Dead {class} plant** ([[features/plants]]).

The Compost box and the Furnace take it; the Pot still does not. Its Almanac page is shared with [[items/produce/rotten-produce]].
