# Graft

| | |
|---|---|
| item kind | `'graft'` |
| unit | count |
| stack limit | `STACK_MAX` (+ `bulk-up`) |
| obtained from | chopping a grown tree with the `grafting` skill: `CHOP_GRAFTS` per chop, of that tree's species and variety |
| sold at | not sold |

A cutting that changes a young plant's variety. Name: **{Crop} ({Variety}) graft**. Grafts merge only with the same crop and variety.

## Use

**Graft** on:

- a growing plant of the same crop that is not Heirloom: the plant takes the graft's variety and quality;
- a tree of the same species that has not finished its juvenile period and is not Heirloom: the tree takes the graft's variety.

One graft per use; the last one leaves the hand empty ([[features/plants]], [[features/trees]]).
