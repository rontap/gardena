# Truffle

| | |
|---|---|
| item kind | `'truffle'` |
| unit | count |
| stack limit | `STACK_MAX` (+ `bulk-up`) |
| obtained from | **Pick up** on a Truffle around a grown tree ([[features/mushrooms]]); a Rare burrow (`TRUFFLE_LOOT_COUNT` per find) ([[features/burrow]]) |
| sold at | not sold |

A dark, knobbly mushroom that comes up on untilled ground around a tree. It does not lose freshness. The Mill crushes it into [[items/produce/truffle-extract]]. The Compost box takes it at `COMPOST_VALUE.truffle` and the Furnace at `FURNACE_VALUE.truffle`, the same values as Fly agaric ([[features/machines]]).
