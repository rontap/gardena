# Weed spray

| | |
|---|---|
| item kind | `'weed-spray'` |
| unit | litres; a bag holds `WEED_SPRAY_BAG` |
| stack limit | 1 bag |
| obtained from | `buy-weed-spray` in the [[items/buildings/additive-store]], after `unlock-better-tools` |
| sold at | not sold |

Clears a weed and keeps a plot free of weeds for longer.

## Use

**Spray** on any tilled plot uses 1 L: the plot's weed chance becomes −1, and a weed on it is removed with nothing dropped. It takes `SPRAY_WORK` seconds. The bag leaves the hand when it holds less than 1 L. The Sprayer trailer does not carry it ([[features/weeds]]).
