# Apple tree

An apple tree is a wild, non-plantable `AppleTree` occupying a 1×2 vertical rectangular footprint. It needs no water. Its growth cycle is 720 seconds. A ripe tree yields one apple using the existing rarity roll; the heirloom apple name is Pink Lady. Common apple sale value is 20 and seed value is 4. One tree is spawned during initial map generation at the first valid vertical 1×2 soft-ground footprint in the starting chunk.

The tree uses dedicated prop and fruit SVGs. Both occupied cells reference the same tree object; interactions on either cell address the full footprint.
