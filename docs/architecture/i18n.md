# i18n

Player strings. English only. Locale `en`, pinned. No picker. [[standards/user-facing-text]]

Paraglide JS. Message files `messages/en/{section}.json`. Compiler emits `src/paraglide/` (gitignored). Sim and React call the same `m.*`.

`npm run dev` / `npm run build` / `npm test` compile through `paraglideVitePlugin`. Edit a JSON, the plugin recompiles, Vite HMR picks it up. `npm run i18n` is the same compile without Vite — CI or a one-shot. Not the edit loop.

`fill()` is gone. Named params on the message. Missing key or missing param is a type error.

Plurals use inlang variants (`match` / `countPlural`), not ICU `{n, plural, …}` — that form does not compile with plugin-message-format@4.

Numbers from `src/game/defs/`. Copy never embeds digits.

Player words for this HUD: **Variety**, **Quality** as a percent, and the three purposes **Fresh**, **Preserving**, **Alcohol**. `tier` and `purpose` are vault-only; the player reads the purpose word and the multiplier on it. New and changed strings are marked for [[agents/game-text-writer]].

| `hud` | ribbon, recap, docks, inspect bar labels. **Variety**. **Quality** as percent. Held / tooltip / silo / Buy-cell seed rows. Held tool uses `hud_line_uses` |
| `skills` | skill name + description |
| `research` | research name + description. Synthetic additives. Gardening tools. Hardened tools. Infusion |
| `almanac` | Overview / Game concepts. Variety page. Quality page. Infusion page. Variety row descriptions |
| `market` | stall, contracts overlay |
| `family` | Family overlay |
| `vehicles` | hangar, dash, routes |
| `sensors` | sensor HUD, wire prompts |
| `menu` | home / gear |
| `tutorial` | tutorial lines |
| `notices` | the notices column — [[ui/notices]] |

Keys unique across files. Prefix `catalog_` `prompt_` `hud_` … `names` is the one source for `Pumpjack`, Variety names, path words. Other files do not duplicate those words.

`skuLabel` / `cropName` / `faceName` / Variety name: total maps `Id → message fn`.

Changelog is not a message file. [[architecture/changelog]]

Authorship of new strings: [[agents/game-text-writer]] edits `messages/en/`. Call `m.*` at the use site so a JSON save shows up on the next paint.
