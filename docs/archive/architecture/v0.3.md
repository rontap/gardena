## Plot

```
type Ground = 'soft' | 'hard' | 'very-hard'
type Cover = { kind: 'bare' } | { kind: 'grass'; variant: 0 | 1 | 2 }

type Plot =
  | { kind: 'untilled'; ground: Ground; cover: Cover }
  | { kind: 'empty'; soil: Soil }
  | { kind: 'infertile' }
  | { kind: 'weed'; soil: Soil; weed: Weed }
  | { kind: 'growing'; soil: Soil; plant: Plant }
  | { kind: 'ripe'; soil: Soil; plant: Plant }
  | { kind: 'dead'; soil: Soil; plant: Plant }
  | { kind: 'rotten'; soil: Soil }

type Tilled = Extract<Plot, { soil: Soil }>
isTilled(c: Cell): c is Tilled
bare(ground: Ground): Plot
```

`soil` is required on every tilled arm — a tilled plot without dirt is unrepresentable. `untilled` and `infertile` have no `soil` field to read. Grass is a `Cover` union, not a nullable variant index.

`isPlot` includes `weed`. `isSolid` unchanged.

## Soil

```
class Soil {
  water: number
  fertilizer: number
  get dry(): boolean       // water < WITHER
  get critical(): boolean  // water < CRITICAL
  drink(l) soak(l) feed(l) starve(l)
}
```

`soak` clamps at `SOIL_WATER_MAX`, `feed` at `FERT_PLOT_MAX`, `drink` / `starve` at 0. Callers never clamp.

Constants in `sim/soil.ts`: `SOIL_WATER_MAX` 1, `SOIL_TILL_WATER` 0.75, `WATER_POUR` 1, `FERT_PLOT_MAX` 1, `PLANT_FERT_PER_SEC` 1/720, `WEED_WATER_PER_SEC` 0.008, `WEED_FERT_PER_SEC` 1/240, `WEED_GROW` 60, `BIG_TICK` 10, `WEED_CHANCE` 0.05, `GRASS_CHANCE` 0.5.

## Plant / Weed

```
class Plant { maturity; freshness; happiness; crop; rarity }   // no thirst
class Weed  { maturity; readonly variant: 0 | 1; stage(): 'sprout' | 'grow' }
```

## Noise

`sim/noise.ts`. Pure function of `(seed, col, row)` — no map is stored, so an expanded chunk agrees with its neighbours for free.

```
goodness(seed, col, row): number   // [0,1]
groundOf(g): Ground
VERY_HARD_MAX = 0.2
HARD_MAX = 0.34
```

3-octave value noise over `hash(seed, 'soil-noise', oct, x0, y0)` with smoothstep interpolation. `DOOR`-centred boost, `r = 8`. Illegal: a second independent roll deciding ground kind.

## World

```
World.bigTicks: number
World.freshSoil(at): Soil          // private
Intent += { act: 'fertilize'; at: Coord }
TaskName += 'Fertilize'
waterable(c: Cell): boolean        // exported for prompt.ts
```

`tickBig(dt)` accumulates to `BIG_TICK`, bumps `bigTicks`, then `sproutWeeds()` + `sproutGrass()`. Both are single passes owned by the world — illegal: a per-cell weed or grass timer.

Weed roll salt: `hash(seed, 'weed', col, row, bigTicks)`. Grass: one `grass-roll`, then up to 24 `grass-col` / `grass-row` samples.

`freshSoil` is the only mint point: tilling fresh ground, and clearing a deleted pumpjack / well / chest / grinder.

## Item

```
Item += { kind: 'fertilizer'; liters: number; capacityLiters: number }
Face += { kind: 'weed' }
```

`weed` is a catalog face only, like `delete` — never an `Item`, never a `SkuId`. `confirmPlace` rejects it.

## Invariants (do not runtime-check)

- `Plant` has no `thirst`
- a tilled `Plot` arm always has `soil`
- `untilled` / `infertile` have no `soil`
- ground kind and fertilizer come from one `goodness` call
- clamping lives in `Soil`, not in callers
- weed and grass spawn from the big tick, never per cell
- `{ kind: 'weed' }` is a `Face`, not an `Item`
- `freshSoil` is the only place a `Soil` is constructed
