# v0.1 UI

Supersedes [[ui/beta-6]] where this file names a replacement. See [[mechanics/v0.1]], [[architecture/v0.1]]. Place [[ui/place]]. Beta-6 chrome holds except below.

## Market overlay

Release display is fixed-price and manual. The overlay shows stocked produce and one **Sell all - {gain}** action. Offered price, market price, ± controls, rarity pips, rarity multipliers, and sale toasts stay in source but are not displayed.

The detailed dynamic row contract below is retained for the later dynamic release and is inactive in this release.

HUD **Market** toggles an App panel overlay. Almanac chrome: `absolute inset-0 z-20 flex items-center justify-center bg-ink/40` + `Chrome`. Not a left `Dock`. Shop / research docks unchanged.

Root `data-market-overlay`. Width `w-[40rem]`. Title **Market**. × closes. Esc closes (App already closes the panel). HUD Market selected while `panel === 'market'`.

Top: `ui-market-stall.svg`, full width of chrome. Do not pin Coin to `#till`. Market price is per row `data-market-price`.

### Empty

Every `StallGood` stock sum is 0: stall SVG + **No produce.** No boxes. No ±.

### Stocked

One row per `StallGood` with stock > 0, `STALL_IDS` order, under the stall SVG.

```
STALL_IDS = carrot potato wheat tomato raspberry watermelon berry
```

Each row `data-stall-box="{id}"`:

| slot | what |
|---|---|
| left | Fruit box Face + crop fruit. Berry: berry Face. Mixed rarity: one box. Quality pips for rarities present (`uncommon` / `rare` / `heirloom`). Common: no pip |
| count | total stock (sum of four rarities) |
| offered | `Coin n={offered}` `data-offered` |
| ± | dirt `Btn` `data-plus` `data-minus`. `nudgeOffered(id, 1 \| -1)`. No labels |
| market | `Coin n={market}` `data-market-price`. No **Market** label |
| right | always, even if those rarities are 0: **Uncommon 1.25×** **Rare 2×** **Heirloom 3.5×** |

± disabled at offered `0.1` (−) and `3X` (+). Disabled token: `bg-house` `text-ink/40` `cursor-default`. Not a second grey.

Offered / market use beta-6 `Coin` (gold+silver, tenths).

### Sale toast

`data-sale-popup` absolute on that row. `Coin` + that sale’s money. Visible 1.2s after a `StallSale` for that id. View-local clock OK.

## Map

Truck prop at `(12,8)`, span 2×1. One 2-tile sprite. `data-truck` on that image.

Yard crate derivation remains in source, but release map renders no yard-crate sprites.

Truck is not a Place SKU. Unarmed click. Click truck cells only → `{ act: 'consign' }`. `dest(consign) = PAD`. Yard / pad clicks stay plot prompts. Delete arm on truck: blocked.

Hover look **Market truck**. Prompt **Drop off**.

## Inventory

No Sell buttons. No `sellSlot`. Fruit / berry `itemLine` / `ItemLineView`: `{name} - {count}`. No money clause.

## Docks

No left market dock. `Dock` is shop / research only.

Beta-6 dock table: drop market. Shop stays `absolute top-16 left-32 z-20` `w-72`. Research same pos, `w-[28rem]`.

## Money

Beta-6 gold+silver `Coin`. HUD, shop, research, overlay offered / market, recap, tax, almanac. Overlay values use `Coin n=`.

## Hooks

| attr | host |
|---|---|
| `data-truck` | 2-tile truck sprite |
| `data-market-overlay` | overlay root |
| `data-stall-box="{id}"` | stocked row; `{id}` is `StallGoodId` |
| `data-offered` | offered `Coin` inside that row |
| `data-market-price` | market `Coin` inside that row |
| `data-plus` | + → `nudgeOffered(id, 1)` |
| `data-minus` | − → `nudgeOffered(id, -1)` |
| `data-sale-popup` | toast on that row |
