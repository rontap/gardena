# Apple tree art

`prop-apple-tree.svg` is a 24×48 vertical two-tile prop with `unripe` and `ripe` groups. `fruit-apple.svg` is a 24×24 hand/box icon with `common`, `rare`, and `heirloom` groups; uncommon uses common. Pink Lady is the red heirloom group. Both use crisp edges, no text, and only the approved cottagecore palette.
