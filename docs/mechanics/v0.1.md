## X / money

```
tenths(n) = Math.floor(n * 10)
```

All offered / rate / money compares use `tenths`.

```
stallX(id, mods):
  id === 'berry' → BERRY_SALE          // 2. No research mul
  else CROPS[id].sale * saleMul(id)
```

`saleMul(crop)` = product of `modifiers` where `crop === undefined || crop === id`, start `1`. Not `RARITY_SALE`. Rarity is paid at stall, not in X.

At construct: `offered = market = target = stallX(id)`. `acc = 0`. `stock` all 0.

Offered ∈ `[0.1, 3X]`, step `0.1`.

```
World.nudgeOffered(id: StallGoodId, dir: 1 | -1): void
  t' = clamp(tenths(offered) + dir, 1, tenths(3 * stallX(id)))
  offered = t' / 10
```

Stall pays `offered * RARITY_SALE[rarity]` per unit. Ignore `unitSale`.

Research sale-mul complete: recompute X for that crop; `market` / `target` clamp into new `[0.25X, 1.75X]`; `offered` unchanged. Berry unchanged.

## Drift / retarget

Every 10s of play `dt` (private beat; pauses in recap): each good, `market` steps `0.1` toward `target`, or arrives if `tenths` equal.

Retarget every good:

- `Clock.t` crosses 120 this tick (`t0 < 120 && t >= 120`) → `slot = 0`
- day seam (`clock.advance` → `'seam'`) → `slot = 1`, then recap as now

```
u = hash(seed, 'mkt-tgt', goodIx(id), clock.day, slot)
target' = clamp(target * (0.75 + u * 0.5), 0.25X, 1.75X)
```

`clock.day` after `advance`. Seam retarget runs on the seam tick before recap freeze. No stall dt during recap.

## Consign

Arrive `PAD`. Then:

Legal cargo (whole lot; count ≥ 1 is enough — partial stacks OK):

- hand `fruit` → lot `{ good: crop, rarity, n: count }`; hand → empty
- hand `berry` → lot `{ good: 'berry', rarity, n: count }`; hand → empty
- box fruit cargo `count ≥ 1` → lot from stack; cargo → empty; box stays in hand
- box berry cargo `count ≥ 1` → lot from cargo; cargo → empty; box stays in hand

Seeds (hand or box), empty box, empty hand: no-op. Hand unchanged.

Lot: `stock[rarity] += n` on `World.stall[good]`.

## Rate / sell

Per good with stock > 0:

```
if tenths(offered) >= tenths(1.75 * market): rate = 0
else rate = min(0.2, 0.1 * market / offered)

acc += rate * dt
while acc >= 1 and stock > 0:
  sell 1 in rarity order common → uncommon → rare → heirloom
  money += offered * RARITY_SALE[rarity]
  sales.push({ good, rarity, money: offered * RARITY_SALE[rarity] })
  acc -= 1
stock 0 → acc = 0
```

Stock = sum of the four rarity counts.

Play `tick`: clear `sales`, then clock / jobs / queue / field / stall. Stall appends this tick's `StallSale`s. Ping if `sales.length > 0`.

## Yard crates

crateCells(seed, stall): { id: StallGoodId; at: Coord }[]
