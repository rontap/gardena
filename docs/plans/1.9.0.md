## Route

A route is a `World` object, not a vehicle. `World.routes: Route[]`. `World.nextRouteId` starts 1.

```
RouteId = number

RouteStop =
  | { kind: 'goto'; x: number; y: number }
  | { kind: 'unload'; at: Coord }
  | { kind: 'load'; at: Coord }
  | { kind: 'wait'; at: Coord }

Route = { id: RouteId; name: string; stops: RouteStop[] }
```

Vehicle holds `route: RouteId | 'none'`, `cursor: number`, `running: boolean`. Edit of a route is live for every assignee. Loop `i = (i + 1) % n`. Zero stops: Start / hangar Automate no-op.

Create names `Route {n}` with minted `id`. Delete route: no-op while assigned.

Goto: in-world XY, not tile-snap. Arrive Euclidean dist ≤ `ROUTE_ARRIVE` (preference). Then next.

Unload: dropoff pad tile. Arrive `floor(x,y)` is that pad. One transfer, same body as dash Unload, then next.

Load: takeup pad tile. Arrive `floor(x,y)` is that pad. One transfer, same body as dash Load, then next.

Wait: traffic-light cell. Arrive `floor(x,y)` is that cell. Hold while light `inn === 0`; on `1`, next.

Pads: mill, still, jam, compost-box, chest, freezer, house seed-silo, additive-store. Not barrel, grinder, field silos. Quad load/unload uses quad slots; tractor still needs hitch (`vehicleCargo()`). Auto transfer is a tick: chest/freezer legal (guest restriction is on `Act.load` / `Act.unload` only).

No dock-stop. Dock stays `Act.dock`.

## Start / hangar / board

Dash Automate / editor open / hangar select: App-local, not logged.

Logged: create / assign / add / remove / reorder / rename / delete route, Start, hangar Automate, place light.

Start: this seat drives that vehicle, `unlock-dispatch` in `done`, route assigned, `n ≥ 1` → disembark, `running` true. Cursor kept (resume).

Hangar Automate: vehicle stored, that hangar, `unlock-dispatch` in `done`, route assigned, `n ≥ 1`. Spawn `padCenter`, heading `HEADING_SOUTH`, speed 0, driver `'none'`, `i = 0`, `running` true. Does not seat. This seat may already drive another vehicle.

Dock: store, keep route, `running` false, cursor kept. Next hangar Automate: `i = 0`.

Embark / Enter on running: pause (`running` false), board, speed 0. Cursor stays. Start from that seat resumes.

Hangar row **Automated** when field, no driver, `running`.

Away / recap: recap still skips integrate (early return before `tickVehicles`). Away while seated: existing (`driver 'none'`, coast). Auto unmanned is not a seated driver.

## Auto motion

Today no-driver coasts to 0. Auto `running` synthesizes `Drive` inside `tickVehicles` (not `Act.drive`, not `Seat.drive`).

Always forward. Yaw in place until heading aligns (smallest-angle `|Δ| ≤ ROUTE_ALIGN`, preference), then throttle 1. No auto reverse. Target: goto `(x,y)`; load/unload/wait pad/cell center `(col + 0.5, row + 0.5)`.

Burn when that synthesized drive has throttle or steer, same formula as a seated driver (`World.skillTier('driving-classes')`).

Empty fuel on auto: stop completely. Drive `{0,0}`, seek speed 0, do not crawl, do not advance stops. `running` stays true so refill-all (field tanks) resumes. Seated empty fuel still crawls (`vehicles.empty` unchanged).

Hitch follows.

Boom: existing predicate, seated driver **or** auto running, so unmanned auto farms. `steer === 0`, `speed > 0`, hitch present.

## Two-phase tick

1. Motion in `tickVehicles` (seated / auto / coast). Goto arrive → next, same phase.
2. After `evalDag`, `tickDispatch`: resolve wait (this tick’s light `inn`) and load/unload. 1-tick-late wait is wrong for a button pulse.

Recap skips both. Vehicle array order.

Arrived wait + `inn === 0`: hold, synthesized Drive `{0,0}`. Arrived wait + `inn === 1`: next. Several waiters on one light: all hold on 0, all leave on 1. No collision.

Arrived load/unload: one transfer then next, even if 0 items moved. Empty fuel: do not transfer, do not advance.

## Traffic light

1×1 sunk sensor. `SensorKind` `traffic-light`. Groups **off** / **on** from `inn` (0 red, 1 green). `in` top, `out` bottom. Unwired `inn` 0 = red = hold. Output 1 iff a vehicle’s current stop is this cell **and** it is waiting on it (running, wait stop, floor is that cell, `inn === 0`). Path-cross is not a wait. `SENSOR_HOLD` on `out`. No collision.

SKU `buy-traffic-light`. Look **Traffic light**. StayArmed. Guest `GUEST_BUILD`. Ports like NOT/lever. `Sku.tab` automation. `haggling`. Sensors shelf, `show` `unlock-sensors`, `need` `unlock-dispatch` (vehicle-detector pattern). Place defaults `inn` 0 `out` 0 `hold` 0. `TRAFFIC_LIGHT_PRICE` preference, reader band.

`inn` this tick in `evalDag` (mill-like). `isSeqIn` includes traffic-light `in`. Sequential feedback through `in` is legal. `out` + hold after `tickDispatch`. Combo reads last tick’s `out`. `inn` does not combinationally drive `out`.

Add wait no-op unless that cell is a traffic-light. Add load/unload no-op unless that coord is a takeup/dropoff pad. Add goto no-op unless `floor` owned. Delete of a light or pad building strips targeting stops (cursor remap); `n === 0` → assignees `running` false.
