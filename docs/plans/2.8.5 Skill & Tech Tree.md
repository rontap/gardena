
High level: "Family" and "Research" get rebalanced, preparation for rewritten for UI as well.  Instead of custom logic for show and prerequisites, show always when previous is researchable. When previous is researched, that one can be researched too. If something is not "show", the UI element is still there but the icon   is "?" and description is "You dont know what this does", disabled.
Skills gain the exact same code system of RequiresPrevious, but they can also be locked by a research being completed. 
In this update, major UI rework is NOT part of it, but family view is removed and replaced with a simple grid like in research view. Tabs are gone from research, just showing everything with the logic described.

Functional changes:
- Wheat is not unlocked by default, multi-crop farming unlocks it
- grape and tomato seperate research -> "Advanced Plants", unlocks both
- "Smart Irrigation" -> "Smart Irrigation Sensors" rename
- Weather Forecast Station: New tall, 2 tall 0.75 wide metallic building with device on top. Replaces weather forecast skill. Buildable multiple times, multiple buildings are no-op. 24$.
- Remove Tree-related experienced ... grower skills
- new skill: Specialty Maker. Jam/Alcohol made from variety/heirloom stuff has +5% sell value, per level.
- Level II skills need 2 Skill points, III : 3 skill points. 
- No level IV or V, broker and inherint land also max III levels
- You gain 1 skill point per day.
- Logic of seperate skills per-character is gone, there is no "owner" for specific sklils, it is one big pool.
