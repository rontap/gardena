# Plant popup stats

Growing plant inspection renders happiness, fertilizer, and water as separate segmented bars.

Each bar contains a dark current-value marker. Green is the ideal range, orange is acceptable, and red is bad. Water is centered on its ideal value and has red zones at both ends. Happiness and fertilizer increase toward the ideal range from the left.

Stat colors are dedicated muted green `#4f9d69`, amber `#d69a3a`, and red `#c9574b`. The current marker is a pale, outlined notch with enough height to cross the bar.

Ripe plant inspection renders freshness as a separate red/green bar with no orange range. Freshness decreases toward the left.

The existing plant title, drop text, and action prompt remain in the popup. Numeric values remain available beside their bars.
